# Cost model

The blockchain token itself is the cheapest component. Professional launch costs come from security, legal/compliance, product engineering, operations and liquidity.

## Phase budgets

| Phase | Purpose | Cash budget principle |
| --- | --- | --- |
| Local development | compile/tests/security review | near zero beyond engineering time |
| Polygon Amoy | testnet deploy + integration | test POL only; no real liquidity |
| Security & legal gate | audit/classification/whitepaper/terms | obtain external quotes before commitment |
| Mainnet technical deploy | token/vault/vesting/Safe | POL gas + verification/ops |
| Public distribution | only after legal gate | separate approved budget |
| Liquidity | only after legal and market-integrity gate | separate treasury allocation, never AutoTrader trading capital |

## Hard separation rule

The current AutoTrader live bankroll is not a token-launch budget. No trading capital should be transferred to the AIHF treasury, liquidity pool, deployer or marketing wallet.

## Cost-control rule

Do not purchase paid liquidity, exchange listings, market-making services, audits or legal packages before:
1. testnet functionality is proven;
2. the product access flow is working;
3. legal classification has been reviewed;
4. a vendor scope and fixed budget are approved.

AFM currently states there is no filing fee for submitting MiCA whitepapers, but drafting, legal review and operating compliance can still have material costs.
